# NYC Airbnb Market Analysis

Analyze 2019 New York City Airbnb listings using Python, Pandas, and Power BI to explore listing distribution, room types, and nightly pricing across boroughs.

## Project Overview

This project examines 48,895 Airbnb listings in New York City to identify patterns in listing concentration, room-type distribution, and nightly prices across the five boroughs.

## Tools & Technologies

* **Python** — data cleaning and analysis

* **Pandas** — data manipulation and validation

* **Jupyter Notebook** — analysis workflow

* **Power BI Desktop** — interactive dashboard

* **GitHub** — project documentation and version control

## Key Findings

* **48,895 listings** were included in the analysis.

* **Manhattan and Brooklyn** accounted for approximately 85.4% of all listings.

* **Manhattan** had the highest median nightly price at $150.

* **The Bronx** had the lowest median nightly price at $65.

Room-type distribution varied by borough, with private rooms making up the largest share in Brooklyn, Queens, and the Bronx.

## Data Preparation

The dataset was cleaned and validated using Python and Pandas. Missing values were handled appropriately, duplicate records were checked, and a separate CSV export was prepared for Power BI to prevent line breaks in text fields from disrupting the import.

## Repository Structure

## Limitations

This analysis uses listing data from 2019 and may not represent current Airbnb market conditions. Listing prices are not measures of actual revenue or profitability.
